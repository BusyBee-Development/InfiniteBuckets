- **Bug reports & feature requests:** [GitHub Issues](https://github.com/BusyBee-Development/InfiniteBuckets/issues).
  Please include your server type and version, the plugin version, and the bucket's entry from
  `buckets.yml` when reporting a bug.
- **Source code:** [github.com/BusyBee-Development/InfiniteBuckets](https://github.com/BusyBee-Development/InfiniteBuckets)
- **Downloads:** [Modrinth](https://modrinth.com/plugin/infinitebuckets)

Before asking for help, check the [FAQ](faq.md) and [Troubleshooting](../advanced-optimization/troubleshooting.md).
